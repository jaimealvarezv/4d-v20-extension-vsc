# Commands Index

Standard 4D Commands are documented in the `docs/` folder, usually under `Commands/`.

Search pattern: `grep -r "CommandName" docs/`

## Categories

*   **Language**: Control flow, variables.
*   **User Interface**: Forms, Dialogs, Menus.
*   **Database**: ORDA, Classic Query, Transactions.
*   **Communication**: HTTP, Mail, LDAP.
*   **System**: File system, Process, Memory.
