# API Index

For detailed API documentation, please refer to the embedded documentation in the `docs/` directory.

## Searching

Use `grep_search` to find specific commands.

## Common APIs

*   **File/Folder**: `File`, `Folder`, `Document to text`, `Text to document`.
*   **JSON**: `JSON Parse`, `JSON Stringify`, `JSON Resolve pointers`.
*   **Process**: `Current process`, `New process`, `CALL WORKER`.
*   **String**: `Substring`, `Position`, `Length`, `Replace string`.
*   **Date**: `Current date`, `String(date)`.
