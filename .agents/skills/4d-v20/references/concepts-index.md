# Concepts Index

Key 4D Concepts documented in `docs/`.

## Core Concepts

*   **Project Architecture**: Project mode vs Binary mode (v20 is Project mode).
*   **Pre-emptive Multitasking**: Use `New process` with `preemptive` option.
*   **Classes**: user-defined classes methods and properties.
*   **Extension Classes**: Extending standard classes.
*   **Shared Objects**: `Storage`, `Use/End use` for multithreaded access.
*   **ORDA**: Object Relational Data Access.
*   **REST Server**: Automatic API generation.

Search `docs/` for these terms to find deep-dive explanations.
